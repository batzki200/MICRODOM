# Микродом Сервис - сайт сервисного центра

Статический сайт (HTML/CSS/JS) + PHP-обработчик заявок. Одностраничник, адаптивный, тёмная тема.

## Структура

```
microdom-service/
├── index.html          # Главная (вся вёрстка + SEO-мета)
├── styles.css          # Стили
├── script.js           # Валидация формы, мобильное меню
├── send.php            # Обработчик заявок (почта + fallback)
├── config.php          # Конфиг: боевой домен, почта для заявок
├── .htaccess           # HTTPS-редирект, секьюрити-заголовки, блокировка служебных каталогов
├── assets/             # Изображения: logo, favicon, иконки карт, apple-touch
└── leads/              # Fallback-заявки (создаётся автоматически, в git не идёт)
```

## Развёртывание

1. Залить все файлы в корень хостинга (`public_html` или `www`).
2. Домен настроить на хостинг (A-запись), включить HTTPS (Let's Encrypt).
3. В `config.php` указать боевой домен (`SITE_DOMAIN`) и почту для заявок (`SUPPORT_EMAIL`).
4. В `index.html` - при смене домена заменить `https://microdom.by/` во всех SEO-мета-тегах (блок помечен комментарием).
5. Проверить: `http://домен/send.php` отвечает JSON (POST-запрос).

## Требования хостинга

- PHP 7.4+ (send.php, config.php)
- Почта: mail() или любой MTA (для отправки заявок)
- При недоступности mail() заявки падают в `leads/` (подстраховка)

## Локальный запуск (для разработки)

```bash
php -S 0.0.0.0:8000 -t microdom-service
```

Открыть http://localhost:8000

## Отправка заявок

Форма уходит на `send.php` POST-запросом (FormData).
Ответ: `{"ok":true}` или `{"ok":false,"error":"..."}`.
Антиспам: honeypot-поле `company`, проверка времени заполнения (<3 сек - бот),
валидация телефона/email на сервере, rate limiting по IP
(не более 5 заявок/час с одного адреса, счётчики в `leads/rate/`).

Fallback-заявки из `leads/` старше 60 дней удаляются автоматически при отправке.
Каталог `leads/` закрыт от прямого доступа (`.htaccess` и правило в корневом `.htaccess`).

## Безопасность (.htaccess)

- Редирект HTTP → HTTPS (301), HSTS при HTTPS;
- Заголовки: `X-Content-Type-Options`, `X-Frame-Options: DENY`, `Referrer-Policy`,
  `Permissions-Policy`, CSP (Google Fonts + iframe карты учтены);
- Запрет индексации каталогов (`Options -Indexes`);
- Блокировка прямого доступа к `leads/` и `vendor/`.

Требует Apache с модулями `mod_rewrite` и `mod_headers` (стандарт на большинстве хостингов).
